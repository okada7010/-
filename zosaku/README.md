# 造作3DCAD（Ver1.2）

建築造作（間仕切り壁の下地・ボード、角材・板材、建具、造作家具）を、mm 単位で3Dに組み立てて、部材表（拾い出し）まで出せる簡易3DCADです。`index.html` 1つで動きます（インストール不要、オフライン可）。

## 開き方

- `zosaku/index.html` をブラウザ（Edge／Chrome）で開く。
- 棚など、部屋なしで1つだけ作るときは「新規」で空の図面にしてから置く。
- 作業中の図面は、そのブラウザに自動で保存され、次に開いたとき続きから始まる。別のPCへ持っていくときは「保存」でJSONファイルに書き出す。

## できること

| 分類 | 内容 |
|---|---|
| 部材を置く | 左の一覧（柱・間柱、下地・角材、板材、床・天井、汎用）から選び、3D画面をクリックして置く。ほかの部材の面に合わせると、その面に付く |
| 壁を描く | 2点クリックで連続して描く。数字＋Enterで長さ指定。角は自動で納め、T字は相手の面で止める |
| 建具・開口 | 左で選んで壁をクリック。位置・幅・高さ・下端高さは数値で直せる |
| 下地に展開 | 壁を、上下枠・間柱（303／455／606／910ピッチ）・開口脇の間柱・まぐさ・窓台・開口上下の短い間柱・ボード（定尺で割付、開口を切り抜き）の部材に置き換える |
| 造作家具 | 箱物・棚（側板・天板・地板・棚板・背板・台輪）、カウンター（天板・側板・幕板）を、寸法を入れて板に分けて作る。背板・台輪を0にすればオープン棚 |
| 壁付け棚（Ver1.1） | 幅・奥行・段数・段の間隔・下の段の高さ・棚受けの数を入れ、壁の面をクリックすると、背を壁に向けて指定の高さに棚板と棚受け金物（L字）が付く。棚受け金物だけを置くこともできる |
| 編集 | ドラッグ移動（刻み・面への吸着）、数値入力（位置・寸法・角度）、90°回転（平面／X軸／Y軸）、複製、配列（等間隔）、グループ、元に戻す・やり直し |
| 見る | 立体／平面／正面／側面、透視・平行投影、断面（指定の高さから上を隠す）、種類ごとの表示切替、寸法線（2点を測って残す） |
| 寸法表示（Ver1.2） | 選んだ部材（なければ図面全体）の外形寸法（幅・奥行・高さ）と、板の割付寸法（棚板の間隔・板厚・側板と内法・壁付け棚の床からの高さ）を自動で描く。正面・平面・側面では、その図で読める側に出る。縦の寸法の数字は横に倒し、重なる内訳の数字は隠す。「画像」で寸法ごと書き出せる。壁・床のある図面全体では外形だけ |
| 出力 | 部材表（角材・板材・壁・床天井・建具・金物、角材と板材の定尺換算つき）→ CSV（Excel用）、画像（PNG）、OBJ（mm、Zが上）、図面（JSON） |

操作の一覧は、画面右上の「使い方」にあります。

## 注意

- 部材の寸法は呼び寸法の目安です。製品の実寸・定尺は仕入先の資料で確認してください。
- 下地の割付は一般的な納まりの目安です。構造・防火・固定方法などの判断は、設計図書と担当者の確認を優先してください。
- 部材表の定尺換算は目安です（継手・端材の使い回し・搬入寸法は含みません）。

## 作りと、作り直し方

```
zosaku/
  index.html        ← 配布物（ビルドで作る。直接は書き換えない）
  build.mjs         ← src をまとめて index.html を作る
  src/core/         ← 計算（画面なし）：geom 幾何／model 図面データ／snap 位置合わせ／
                       framing 下地割付／cabinet 造作家具・壁付け棚／dims 自動の寸法／cutlist 部材表／catalog 材料と部材一覧／sample
  src/ui/           ← 画面：view3d（three.js の3D表示）／app（操作）／style.css／index.template.html
  test/             ← core.test.js（計算の確認）／e2e.mjs（画面を実際に操作する確認）
```

```
cd zosaku
npm install                      # three.js と esbuild（初回だけ）
npm test                         # 計算の確認
npm run build                    # index.html を作る
NODE_PATH=$(npm root -g) node test/e2e.mjs   # 画面の操作の確認（Playwright が必要）
```

- 版は `build.mjs` の `VER`。ファイル名とアプリ内の版を同時に上げる。
- 部材や材料を足すときは `src/core/catalog.js` を直す。

### データの約束

- 座標は mm。X＝左右、Y＝奥行、Z＝高さ。
- 部材はすべて「中心 `c`・ローカル寸法 `s`・回転 `r`（度。X→Y→Z の順に固定軸で回す）」の箱。
- 角材は `s[0]` が長さ、板材・床は `s[2]` が厚さ、壁は `s`＝［長さ, 厚さ, 高さ］で、開口は壁の始点からの位置で持つ。
- 金物（棚受け）は `s`＝［幅, 腕の長さ, 縦の長さ］で、背（壁の側）が +Y。造作家具・壁付け棚は正面が -Y。
- 部材表はこの約束で数える（断面より短い端材でも、長さを取り違えない）。

### 方式の選び方（Ver1.0）

| 案 | 内容 | 判断 |
|---|---|---|
| 箱の部材を組む方式（採用） | 角材・板材・壁を「寸法つきの箱」で持ち、置く・動かす・数値で直す | 造作は直方体の部材がほとんど。寸法と数量がそのまま部材表になり、操作も覚えやすい |
| スケッチ＋押し出しの汎用モデラー | 面を描いて押し出す・切り欠く | 自由な形は作れるが、操作が増え、部材の数量を拾いにくい |
| 2D平面図から自動で立ち上げる | 間取りを描くと壁・天井が立つ | 部屋の検討には向くが、下地や家具を1本ずつ扱う造作には粗い |

単一HTML・three.js 同梱は、既存のレイアウトツールと同じ配り方に合わせたものです。
